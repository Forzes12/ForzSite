# Forzes HUB - Система совместимости ПК

## Описание
Система позволяет пользователям проверить, подходит ли их компьютер под системные требования игр и приложений на сайте Forzes HUB.

## Состав проекта

### 1. Бэкенд (Python, FastAPI) — папка `backend/`
- `main.py` — API сервер с эндпоинтами:
  - `POST /api/v1/users` — создание пользователя
  - `GET /api/v1/users/{id}` — получение пользователя
  - `POST /api/v1/pc-specs` — сохранение характеристик ПК в профиль
  - `GET /api/v1/pc-specs/{id}` — получение характеристик ПК
  - `POST /api/v1/games` — добавление игры с требованиями
  - `GET /api/v1/games/{id}` — получение игры и требований
  - `POST /api/v1/compatibility` — проверка совместимости игры с ПК
- `models.py` — SQLAlchemy модели (User, PcSpecs, Game)
- `schemas.py` — Pydantic схемы
- `database.py` — подключение к SQLite
- `requirements.txt` — зависимости Python
- `start.bat` — скрипт запуска

### 2. Десктопное приложение (Python) — папка `desktop_app/`
- `pc_collector.py` — собирает характеристики ПК (CPU, RAM, GPU, OS, диск) и отправляет на сервер
- `requirements.txt` — зависимости
- `build_exe.bat` — сборка в .exe через PyInstaller

### 3. Фронтенд — `index.html`, `css/style.css`
- Модальное окно "Проверка совместимости устройства" с кнопками "Скачать" / "Позже" (показывается один раз)
- Подсветка требований в карточках игр: зелёный = подходит, красный = не подходит
- Блок характеристик ПК в профиле пользователя

## Установка и запуск

### Предварительные требования
- Python 3.9+ (не установлен на текущем компьютере, нужно установить с python.org)

### 1. Запуск бэкенда
```cmd
cd d:\Forzes HUB\backend
pip install -r requirements.txt
python main.py
```
Сервер будет доступен на `http://localhost:8000`

### 2. Сборка десктопного приложения
```cmd
cd d:\Forzes HUB\desktop_app
pip install -r requirements.txt
pip install pyinstaller
pyinstaller --onefile --windowed --name "ForzesHubCompatibility" pc_collector.py
```
Готовый `.exe` появится в папке `dist/`. Скопируйте его в `backend/static/ForzesHubCompatibility.exe` для скачивания с сайта.

### 3. Запуск сайта
Откройте `d:\Forzes HUB\index.html` в браузере.

## Как это работает

1. Пользователь заходит на сайт → появляется модальное окно:
   - "Для проверки совместимости вашего устройства необходимо скачать наше приложение..."
   - Кнопка "Скачать" (слева) — скачивает десктопное приложение
   - Кнопка "Позже" (справа) — закрывает окно

2. Пользователь запускает десктопное приложение → оно собирает характеристики ПК и отправляет на сервер → данные сохраняются в профиле пользователя

3. Пользователь возвращается на сайт и открывает карточку игры → рядом с требованиями отображается:
   - 🟢 Зелёным — характеристики, которые подходят
   - 🔴 Красным — характеристики, которые не подходят
   - Общий статус: "Полностью совместимо" / "Частично" / "Не совместимо"

## API URL
По умолчанию бэкенд запускается на `http://localhost:8000`.
Измените `API_BASE` в `index.html` и `pc_collector.py`, если сервер на другом адресе.
